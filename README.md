\# SmartInvoiceParser



ASP.NET Core Web API for managing invoices (`Invoice`) and their line items (`InvoiceItem`) using Entity Framework Core and SQL Server.



\## Tech Stack

\- C# / ASP.NET Core Web API

\- Entity Framework Core

\- SQL Server



\## Endpoints

\- `GET /api/invoices` — Get all invoices with items

\- `GET /api/invoices/{id}` — Get a single invoice by ID

\- `POST /api/invoices` — Create a new invoice with items

\- `PUT /api/invoices/{id}` — Update an existing invoice

\- `DELETE /api/invoices/{id}` — Delete an invoice
